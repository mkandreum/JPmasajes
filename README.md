## ¿Qué es JPmasajes?

JPmasajes es una plataforma web desarrollada por Xyon Platforms para la gestión y reserva de servicios en centros de masajes y bienestar. Permite a los clientes consultar servicios, hacer reservas y a los administradores gestionar su agenda y cartera de clientes.

## ✨ Funcionalidades

- **Catálogo de servicios** con descripciones y precios
- **Sistema de reservas online**
- **Panel de administración** para gestión de citas y clientes
- **Diseño responsive** adaptado a móvil y escritorio
- **Despliegue self-hosted** vía Docker y Coolify

## 🛠️ Stack técnico

| Capa | Tecnología |
|------|----------|
| Frontend | React + TypeScript + Vite |
| Backend | Node.js + TypeScript |
| Despliegue | Docker + Coolify |

## 🚀 Instalación

```bash
git clone https://github.com/mkandreum/JPmasajes.git
cd JPmasajes
cp .env.example .env
docker-compose up -d
```

### Desarrollo local

```bash
npm install
npm run dev
```
